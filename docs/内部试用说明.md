# jackbot 内部试用说明

写给不写代码的同事。照着做大约 15 分钟能聊上第一句话。遇到问题找 PM Karpa 或开发工程师 Bill。

> 版本：分支 `cut-2026-11-14-parity-1`（PR #3），2026-11-15 更新。这是内部试用版，还没合进 main。

## jackbot 是什么

jackbot 是装在你自己电脑上的「AI 同事」应用。打开网页就能和几位预置的同事对话：Chief（幕僚长）、Researcher（调研）、Inbox Keeper（收件箱）、Market Watch（市场观察）。每位同事有自己的浏览器和文件夹，要对外做事（发消息、发邮件之类）时会先弹出审批卡，等你点批准。

它要接一个 AI 模型才能说话。内部试用用我们的中转站。

## 一、准备（每台电脑只做一次）

需要两样东西：

1. **Node.js 22 或更新版本**：到 <https://nodejs.org> 下载 LTS 版安装，一路下一步。
2. **Git**：到 <https://git-scm.com/downloads> 下载安装。Mac 第一次在终端敲 `git` 时，系统会提示安装，点安装即可。

然后打开「终端」：

- **Windows**：开始菜单搜 `PowerShell`，打开。
- **Mac**：启动台搜 `终端`（Terminal），打开。
- **Linux**：打开 Terminal。

在终端里依次输入下面几行，每行回车一次：

```bash
corepack enable
git clone https://github.com/Jacktan007/jackbot.git
cd jackbot
git checkout cut-2026-11-14-parity-1
corepack pnpm install
```

- 仓库是公开的，`git clone` 不需要登录。
- `corepack enable` 在 Windows 上提示权限不足：用「以管理员身份运行」重新打开 PowerShell 再执行一次。
- 最后一行会下载依赖，第一次要一两分钟，看到 `Done` 就好了。

## 二、启动

每次使用都在 `jackbot` 文件夹里执行：

```bash
corepack pnpm dev
```

终端里会出现一行：

```
[jackbot] sign in → http://127.0.0.1:47821/auth?token=……
```

按住 Ctrl（Mac 按住 Command）点这条链接，或者整条复制到浏览器打开。**要用这条带 token 的链接**，直接打开 `http://127.0.0.1:47821` 会提示没登录。

- 刚启动还没填 key 时，终端会说 `no model key yet`，这是正常的，下一步在网页里填。
- 用完关掉：回到终端按 `Ctrl + C`。终端窗口开着，jackbot 才在运行。
- 下次再用：打开终端，`cd jackbot`，再执行 `corepack pnpm dev`。

## 三、填中转站 key（只填一次）

中转站的 key 和地址向 Karpa 或 Bill 私下要，**不要发在群里，不要截图外传**。

1. 在 jackbot 网页左侧栏点 **「AI 模型」**。
2. 在「默认」这一行点 **「编辑」**。
3. 按下面填：
   - **服务商**：选「其他」分组里的 **「自定义地址」**；出现「接口」时选「OpenAI 兼容（Chat Completions）」。
   - **地址**：填中转站地址（形如 `https://……/v1`，向 Karpa 要）。
   - **模型**：填 `gpt-6-astra`（2026-11-15 实测可用）。
   - **API key**：粘贴中转站 key。
4. 点 **「测试」**，看到「连上了，gpt-6-astra 可以用。」再点 **「保存」**。不用重启。

key 只存在你自己电脑上（`gateway/data/llm-key`，只有你的账户能读），不会进代码仓库，网页上也只显示首尾几位。

测试提示「key 没被认」：重新复制一遍 key；提示「这家没有叫 … 的模型」：模型名打错了，或者那个模型暂时不可用，换 `gpt-6` 再测。

> 懂命令行的同事也可以不进网页，启动前设环境变量：Mac/Linux 用 `export JACKBOT_API_KEY=…`、`export JACKBOT_API_BASE=…`、`export JACKBOT_MODEL=gpt-6-astra`；Windows PowerShell 用 `$env:JACKBOT_API_KEY="…"` 这种写法。这样设的值，网页里会显示「由环境变量设定」，改不了。

## 四、第一步可以做什么

1. 左侧点 **Chief**，在底部输入框说「你好，用一句话介绍你自己」，几秒后会回话。
2. 让 Chief 帮你梳理今天的任务、定负责人和截止时间。
3. 左侧也可以点别的同事单独聊。

2026-11-15 用中转站实测：对话、回中文、调用测试用的 MCP 工具、发送前弹审批卡，都走通了。

## 五、已知限制（试用前请看完）

> ⚠️ **暂时不要给 jackbot 配置任何能对外发送的连接器**（发邮件、发 Slack、发消息、改线上数据的 MCP 工具，比如 Slack、Notion、GitHub 预设）。离线走查时，测试用的「发送笔记」工具一度没弹审批卡就执行了；用真模型复测时审批卡正常弹出，但这个差异还没查清楚。查清修好之前，只用 jackbot 聊天和查资料。

下面这些是 2026-11-14/15 走查发现、这一轮**没有修**的问题：

1. **对外 MCP 工具审批**：见上面的警告。另外真模型下发送类操作可能要批准两次（同事自己先问一次，网关再拦一次），属于体验问题，第二次批准后才真的发送。
2. **例行任务（定时任务）**：「例行任务」面板显示「还没有」，没有新建按钮。在聊天里让同事建一次性任务时，曾经弹出一张无关的审批卡（问要不要发 4 封排队中的邮件草稿），任务也没建成。**看到这张卡请点拒绝，不要批准**。定时任务这一轮先别用。
3. **离线演示模型会说假话**：只有用 `JACKBOT_MODEL=stub` 离线启动时才会遇到，它可能说自己「看了六个网页、都归档了」，其实什么都没做。接了中转站 key 就不是这个模型。
4. **「电脑」面板一片空白**：同事的电脑画面没连上时，面板不提示原因，只是空白。不影响聊天。
5. **「连接器」面板写着「还没有连接器」**：即使测试用的工具在运行也这么写，以实际为准。
6. **浏览器标签页没有图标**（favicon 404），不影响使用。
7. **不能删除同事**：界面上没有删除同事的入口。

其他说明：

- 只在本机用：网页地址是 `127.0.0.1`，同一局域网的别人打不开，这是有意的。
- 用量和费用：每句对话都走中转站，按中转站的计价扣费。别让同事长时间跑任务。
- 中转站个别模型偶尔会返回「Service temporarily unavailable」，换一个模型（比如 `gpt-6-astra`）即可。
